# AI 驱动的业务稳定性自动化巡检 Agent 设计与实现

> 同花顺 二面作业题（2~3 天完成）

## 适用说明

1. 作业形式：居家独立完成，不限开发语言（Go/Python/Java 均可）
2. 实现自由度：允许接入大模型 API、AI 聚类算法、智能规则推理等任意 AI 方案
3. 考察核心：自动化巡检流程设计、业务指标理解、异常规则引擎、AI 异常归因、工程模块化能力
4. 完成周期：建议 2-3 天提交（代码 + 设计文档 + 巡检报告）
5. 所有设计需对齐企业级业务稳定性 SRE 巡检规范，具备落地可用性

## 一、业务背景

传统业务稳定性巡检依赖人工定时核查接口成功率、延时、报错、流量、资源负载等数据，存在巡检滞后、漏检、无法智能归因、无标准化报告等问题。随着微服务数量增多，人工巡检成本极高，急需一套 **AI 赋能的业务稳定性巡检 Agent**，实现全自动、智能化、可复盘的常态化稳定性巡检。

## 二、整体要求

1. 支持模拟/对接业务监控数据源（日志、接口指标、系统资源指标均可）；
2. 实现全自动定时巡检、异常识别、风险分级；
3. 引入 AI 能力完成异常根因分析、稳定性打分、优化建议输出；
4. 代码工程化、模块化、可配置，具备日志、异常处理、配置文件管理；
5. 支持容器化打包，可适配 K8s 常驻部署（方案设计即可）。

## 三、必须实现的核心功能

### 1. 巡检数据源接入模块

支持两种方式任选其一：

- 读取本地结构化巡检指标文件（QPS、成功率、P99 延时、错误数、CPU/内存负载）；
- 模拟 HTTP 监控接口拉取实时业务指标数据；

完成数据标准化解析、清洗、结构化存储。

### 2. 多维度稳定性规则巡检引擎

覆盖业务稳定性核心巡检维度：

- 业务层：接口成功率下跌、流量突增/突降、报错量飙升、业务链路异常
- 性能层：P95/P99 延时超时、响应抖动
- 资源层：CPU 高负载、内存占用过高、连接数打满

实现：自动匹配阈值、识别异常实例、标记异常级别（紧急/严重/一般/轻微）

### 3. AI 智能分析核心模块（必做）

任选一种 AI 方案实现：大模型 API / 本地小模型 / 机器学习聚类异常检测

AI 必须输出：

- 本次巡检整体稳定性评分（0-100 分）
- 所有异常项智能根因推理（流量波动、资源瓶颈、代码异常、依赖故障等）
- 针对性可落地修复建议、稳定性优化方案
- 巡检风险总结与稳定性趋势判断

### 4. 巡检报告输出模块

- 控制台结构化输出巡检结果、异常清单、风险等级；
- 支持导出 Markdown 完整巡检报告；
- 记录巡检日志，支持多次巡检结果对比。

## 四、可选加分功能

1. 支持动态阈值巡检，适配业务波峰波谷，替代固定阈值；
2. 实现巡检告警推送（钉钉/企业微信 模拟即可）；
3. 支持服务维度、集群维度多粒度巡检统计；
4. 简单 CLI 交互，支持单次巡检、定时巡检手动触发。

## 五、交付物要求

1. 完整可运行源代码；
2. 系统设计文档：架构图、模块职责、巡检规则设计、AI 集成方案、数据结构说明；
3. 完整 AI 智能巡检输出报告示例。
